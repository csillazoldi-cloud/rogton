# Decision — a real example photo in the "Kész munka" sample image (c14, 2026-10-08)

**Decided by:** Csilla (chat, 2026-10-08 15:05). Hub chunk c14.

**What it replaces:** Csilla's 2026-10-01 note in `apps/web/app/_kozos/R15MunkaMinta.tsx` — "nem stock-fotó": before a photo is uploaded,
the template's photo slot shows a neutral striped placeholder with a small "fotó" label. That note is superseded; the comment now
carries this decision.

**Why:** the striped placeholder keeps confusing users on the phone Kezdőlap. Tibor gate 2026-10-06 18:36: the judge read it as an
upload field ("where do I upload?"), even after the quiet "Minta" corner mark (0144) was added. Csilla accepted that red and opened c14
to replace the stripes with a real example photo.

**Source and licence:**
- Magnific (Freepik) photo id **12455263**, "Natural grass close up" — fresh grey paving stones edged by green lawn.
- Downloaded by Csilla with her **paid** Magnific account on 2026-10-08. Paid plan licence: **no attribution required**.
- Original 2576×1717 (sRGB). Committed copy: `apps/kepgyar/minta/kesz-minta-terko.jpg` — 1600×1066, JPEG quality 82, progressive,
  all metadata (incl. the sRGB ICC profile) stripped, 312 kB.

**What changes:** only the sample image of the "Kész munka" template — POST `/helyzet-minta` of the image maker, which serves
GET/POST `/api/vizual/helyzet-minta/kesz` (Kezdőlap and Hírek offers via `R15MunkaMinta.tsx`, the Képek card, the Arculat
"Így néz ki" preview). The image maker puts the photo into `tartalom.fotok[0]` — the same path an uploaded photo takes — so the
template draws it with its normal photo element (`packages/vizual-core/src/helyzet.ts` `foto()`), centre-cropped.

**What does not change:** layout, text, colours, logo, the quiet "Minta" corner mark on the page (measured: the text block of the
1080×1350 sample is pixel-identical before/after); the editor image (POST `/helyzet`, Kitolto.tsx) — there the striped slot still marks
where the user's photo goes; any request whose content already carries a photo or asks for before/after; the other six templates
(e.g. "Új" keeps its striped sample — out of scope of c14). If the photo file cannot be read, the sample falls back to the stripes.

**Deploy:** the change lives in `apps/kepgyar` only. The image maker's fingerprint (`apps/kepgyar/indit.sh --ujjlenyomat`: the
Dockerfile's COPY sources, incl. `apps/kepgyar`) changes, so the Gigabyte robot rebuilds and restarts `km-kepgyar` on the next
deploy (`indit.sh --ha-valtozott`, called by `nas/teljes-kirakas.sh` and `nas/kirak-sha.sh`). The web image is unchanged in behaviour.

**Cost to note:** the sample PNG grows from ~76 kB to ~1.3 MB (photo content in a PNG). It is cached per workspace in the image
maker; the browser fetches it with `no-store`. If the phone Kezdőlap feels slow, the next step is a JPEG/WebP sample response — a
separate decision.
