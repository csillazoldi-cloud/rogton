## What changed

- **`program/horgony.ts` (pure, the day is a parameter):** `horgonyJavaslatok(rendezveny, tetelek, fajtak, nyelv)` — countdown start −14,
  −7, −3, −1 · tomorrow's programme each day −1 · today's programme each day · performers: the main stage's evening concerts (F7
  `kiemeltTetelek`), on the nearest free day −1…−3, ≤ 1 a day · practical info −5 and −1 · album each day +1 · thank-you end +1. Daily caps
  2 before the event, 3 during and after; the order inside a day: today's > tomorrow's > countdown > album > thank-you > performer >
  practical. Days are Bucharest calendar keys stepped at noon UTC (`poszt/naptar.ts napHozzaad`) — DST-safe. Key
  `program:<fajta>:<the programme day | the posting day>[:<item id>]` — the F7 slice reads it back. `horgonyFajtak(tema_terv)`: the topic
  plan's festival kinds, or all seven when none is marked. `esedekesOtletek` (today … +2, not yet a post, ≤ OTLET_MAX = 3), `szellemSorok`.
- **`program/otletek.ts`:** the profile + programme + existing posts (their `forras.azonosito`) → the ideas; company or no dates → null.
- **Kezdőlap (`r15/index.ts`, `R15Kezdolap.tsx`, rajz D7a):** a festival's due ideas fill the idea slots (max 3). The big card is the idea
  due TODAY (else, when no post waits, the first idea): a quiet line („Holnapi program · okt. 18.”), the title („Holnap: Blahalouisiana és
  Alina Eremia”), primary „Megírjuk”; the newest waiting post moves into „Még N javaslat” with the other ideas. Title count = waiting posts +
  ideas; with ideas and no waiting post the page is „dolgos”. A company has no ideas → nothing changes (0 px).
- **Naptár (`Naptar.tsx`, rajz D7b):** ghost rows on their day, from today on (phone day view + desktop week columns): dashed, code font,
  muted text (the drawing's `.r8-szellem`), one quiet „Megírjuk”. An idea that already became a post has no ghost.
- **„Megírjuk” (`app/_kozos/C30Horgony.tsx`):** POST /api/poszt with `forras {tipus: terv, azonosito: <key>}` and the new optional
  `javasolt_nap` (the anchor day; set only on a NEW post, valid day only) → the Posztszöveg page. Twice → the same post (A-8).
- **Event image (`app/kepek/uj/[helyzet]/page.tsx`):** opened from an anchored post, the `esemeny` image is filled from the anchored item
  (mi = name, hol = venue, mikor = „okt. 21., 20:00”); a day-anchored post gets the day and the event's town. A saved image (?szerk=1) wins.
