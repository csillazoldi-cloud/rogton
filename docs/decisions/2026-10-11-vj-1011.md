## Root causes (measured)

- **#9 logos (phone):** a phone upload is a camera photo (3–5 MB JPG). The logo places only show a file the image maker can use —
  `kepreAlkalmasLogo` in `packages/fajl-core/src/logo.ts:16` requires < `KEP_LOGO_MAX_BAJT` = 2 MB (`logo.ts:12`). The upload itself
  succeeded (201), but the file never appeared in a place, and the overview offered „Válassz logót a cégnevedből” as if nothing had been
  uploaded. From a desktop the same person uploads a small exported PNG, which shows. Reproduced at 390 px with a 3.6 MB JPG.
  **Fix:** `app/fiok/arculat/logok/LogokFeltoltes.tsx` `kepreMeretez` — before upload the browser shrinks an over-limit image (canvas,
  longest side ≤ 1600 px, PNG if transparent, else JPEG 0.9, halving until it fits). Measured after: the photo shows in its place and on
  the overview. No width-dependent code path was found: overview and logo page use the same data and the same `hasznaltLogok` at both
  widths (checked with legacy-shaped rows too).
  **Not fixed (needs a decision):** (a) logos already stored above 2 MB stay invisible — the owner has to upload again (now shrunk);
  (b) several old-style uploads (pre-R-16 rows with no place, `logo_valtozat` NULL) all count as „világos”, so only the newest one shows
  — measured with two legacy rows.
- **#2 logout (phone):** it is in the ☰ menu, but the menu hangs off the sticky top bar (z-index 50), is not height-bounded and does not
  scroll; the page's fixed bottom bar (`r15-also-sav`, z-index 60) sits on top of it. At 390 × 664 (iPhone Safari visible height) the
  „Kijelentkezés” row was at 643–681 px — under the bottom bar and below the screen, unreachable. **Fix:** `app/_kozos/felsosav.css`
  (phone): with the menu open the bar goes above the page bar (72), the menu is at most the screen height and scrolls, and the
  Nyelv · Kijelentkezés row sticks to its bottom. Same elements, same order. After: 597–635 px, on screen.
- **#8 font names (phone):** the family name was desktop-only (`Betuk.tsx:180`). Now on every row at both widths; the overview shows the
  built-in font's name next to its mood word („Tiszta · Public Sans”). Drawing `design/R16-arculat/R16-arculat.dc.html` updated
  (10 overview rows, 5 phone 12e rows); probe on the drawing 17/17 green.
