## What changed

- **Phone upload (D8a), `app/poszt/C30Album.tsx`:** the native picker (`accept="image/*"`, `multiple`, no `capture`). Per photo, one at a
  time: the capture time from EXIF (`album/exif.ts`: DateTimeOriginal + OffsetTimeOriginal, fallback DateTime, else the file's time) is read
  BEFORE re-encoding; `createImageBitmap(file, {imageOrientation: "from-image"})` → canvas → JPEG q 0.82 (0.72 / 0.62 if still > 2.5 MB),
  `nagy` ≤ 2048 px and `kicsi` ≤ 512 px. Re-encoding drops EXIF and GPS. Upload `nagy`, then `kicsi` with `x-album-par`; 3 retries
  (1 · 2 · 4 s) on network/5xx; 413/429/409 stop the batch with the label sentence. „N / M feltöltve” with the shared progress bar;
  uploaded photos show as 64 px tiles, the rest as dashed places; „Még fotók”. A photo the browser can't decode: one sentence, the rest go on.
  A refresh keeps what arrived: the page reads `GET /api/poszt/[id]/album` and, if photos exist but were never picked, starts the pick.
- **The pick (`album/poszt.ts`):** `POST /api/poszt/[id]/album` → 202 and runs in the BACKGROUND (vision + caption can pass the NAS nginx's
  60 s; the F6b gotcha); the page polls every 2 s while `forras.album.allapot = "fut"` (5 min → stale). The working state is visible
  („Kiválogatjuk a legjobbakat” / „Válogatjuk a fotókat…”, D8a's layout). The machine: `mellekletOlvas` with the new `album_valogatas`
  task and prompt (`prompts/album_valogatas.hu.md`), the `kicsi` copies, `detail: "low"`, max 40 (new `max` / `reszlet` options; other
  callers keep 6 and no detail). Answer `{valasztott:[{i, leiras}]}` → `valogatasErtelmez` (1-based, no repeats, ≤ 20). Without the machine
  (test AI, no key, bad answer): capture-time order, 10 evenly spaced, first and last included (`gep: "sorrend"`). Never blocks.
- **The caption:** `poszt/index.ts albumFeliratKeszit` — `tipustKeszit(…, "album", <photo descriptions>)` (the F7 prompt already says the
  album caption may only state what the descriptions and the linked programme item say; the programme slice comes from the profile input),
  and in `egyben` mode the second language by the existing faithful translation (two cells, the D6 bilingual field).
- **Done (D8b):** „Kész a fotóalbumod · {n} fotót választottunk, ebben a sorrendben.”, chips under the title (as drawn), the 96 px strip with
  the number and the „…” button, the caption field (bilingual in egyben), „Fotók hozzáadása” (uploads more, then picks again), bottom bar
  „Megosztom” with the quiet „A szöveget is kimásoljuk.” left of Visszajelzés (`.r15-also-nyugtato`). The „Téma: …” line under the post is
  not shown in the photo states (D8a–c show nothing below the photos); it stays for every other post.
- **Megosztom:** it books the post like „Kész, másolom” (caption to the clipboard, post done). Phone (`pointer: coarse`): Web Share with the
  photo FILES in post order (`01-….jpg`), pre-fetched when D8b opens so the share runs inside the tap; without file share: the photos
  download one by one. Desktop: the F9 ZIP. Always authenticated, no public link.
- **Reorder (D8c):** the shared `.c30-lap` bottom sheet (Visszajelzés and the bottom bar hidden while open): Előrébb / Hátrébb (one place;
  the first photo has no Előrébb, the last no Hátrébb — the remaining move is the sheet's primary), Kiveszem („A fotó megmarad.” — it stays on
  the phone; on the server it moves with its pair to `_torolni/`, frees quota, decision 1), Mégse. `PUT /api/poszt/[id]/album`
  `{muvelet: "sorrend" | "kivesz"}`; a foreign id → 400/404.
- **Album key = post id (decision 2):** `POST /api/album/foto` now checks the post exists in the org (else 404). The F9 test moved to real
  posts (reason in the test). `GET /api/album/foto?album=` lists an album.
- **Contract:** `PosztForras.album` (`PosztAlbum`: fotok ≤ 20 `{fajl_id, leiras}`, allapot, kezdve, gep), read with `.catch` so a bad value
  never makes a post unreadable. `FeladatTipus` + `album_valogatas`.
- **D7 + F10:** the hourly move now gets the posts' use (`albumHasznalatPosztokbol`): a photo in a post moves 30 days after „Kitettem”, or
  30 days after the post's last change while not posted.
