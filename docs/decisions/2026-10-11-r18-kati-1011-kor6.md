## Decisions — features (Round 6)

8. **Továbbiak menu → visible quiet buttons + links** (Rövidebben, Bővebben, Közvetlenebbül, Tárgyilagosabban, + Hashtagek, Új változat;
   links ↶ Visszavonás, Eredeti hír, Más nyelven, Hivatalos nevek · N, Csak másolás). Nothing removed; the „Mit írtál át?” link is kept.
9. **Image-size hint** per platform under/above the preview, values from `r15/platform-aranyok.ts KEP_MERET` (FB/IG 1080×1350 4:5, LI
   1200×1200, blog 1200×630).
10. **Call-to-action („Mire hívod az olvasót?”) stored on the post** as `forras.cta[<language>]` (existing jsonb, contract field optional).
    „Beleírom” makes it the last paragraph (before a trailing hashtag line, replacing the previous CTA); every regeneration/rewrite gets it as a
    fixed line and puts it back last; a translation derives the CTA in the target language. Suggestion only from the company website (no
    phone number is stored anywhere).
11. **Hivatalos nevek stored in the EXISTING `szervezet_profil.adatok` jsonb** (`hivatalos_nevek: [{hu, ro, en}]`, ≤ 200). No new table, no
    RLS/policy change: the row's existing policy covers it; tested that another organisation sees an empty list. Consequence: it needs an
    approved company profile (without one the page says so and `PUT` returns 409). **Editors may edit it** (`PUT /api/profil/nevek` =
    szerkeszto; GET = member) — the people who write the posts know the names; the rest of the profile stays owner-only. *Vilmos to confirm.*
    The names reach every prompt that carries the profile block (`profilSorok`: post text, rewrite, translation, language fit, image
    translation) as a binding block, plus a post-check (`nevCsere`) that swaps another language's form for the official one in the target
    language. Re-approving the profile keeps the list. Page: `/fiok/nevek` (linked from Szervezet adatai and from the post page).
12. **Emoji picker:** desktop popover, phone bottom sheet; recent list in `localStorage` (`km-emoji-legutobbi`, 16, try/catch); inserts at
    the caret.
13. **Image from a post → template step first** (`/kepek?poszt=`): the suggested template is preselected (news-based post → Fontos hír,
    otherwise Kész munka), „Ezzel folytatom” opens the existing editor with the post context; the template thumbnails use the post's text.
14. **Two-language image:** Magyar | Román switch on the preview (only the preview changes), „Mit töltsünk le?” Magyar · Román · Mindkettő
    (default = the language shown). Mindkettő = two PNG files (`kep-<sablon>-<méret>-hu.png` / `-ro.png`) — the existing download path is a
    data-URL per file, no zip. Migration **0169** (174 label rows).

15. **The floating Visszajelzés button never covers content** (coordinator review). It floats only where the page reserves a strip for it
    (phone pages with a bottom bar: header · scrolling content · feedback strip · button bar); everywhere else it stands at the end of the
    page, right-aligned. The layout audit got a matching check (`lebego-takar`).
