# Tokenek — R-7b

Új token **nem kell**; a lap az R-7e új értékeivel áll (lásd `R-7e-vizualis-alap/tokenek.md`).

| Token | Hol |
|---|---|
| `--fs-metric` (30px) | a Hírek csempe „7” száma a kezdőlapon |
| `--panel-soft`, `--line` | a keskeny üzemállapot-sor és a semleges tartalomötlet-doboz |
| `--src-ai` / `--src-ai-bg` (**új érték: semleges**) | a „javaslat” jelvény a beállító és pontosító lapon |
| `--warn` / `--warn-bg` / `--warn-border` | **csak** a forráshiba mondata és a nem mentett változás jelzése |
| `--ok` / `--ok-bg` | a működő forrás jelzése (a lista sorában szóban, jelvény nélkül) |
| `--control-min` (46px) | minden gomb, chip, forrássor-művelet — telefonon is |
| `--lista-max` (1180px) | a lista és a kezdőlap tartalomszélessége |
| `--urlap-max` (680px) | nem itt: a beállító lap 760px, mert a forrássoron három művelet fér el (kivétel, jelezve) |

Megjegyzés: a kategória-jelvény (fontos · érdekes · háttér) **nem** színnel különbözik, hanem szóval — így a Theme színcseréje nem forgatja fel a jelentést.
