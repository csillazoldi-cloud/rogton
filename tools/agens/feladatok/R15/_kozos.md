KÖZÖS SZABÁLYOK (R-15 · 2. szállítmány — minden lapra):
- **A rajz a szerződés.** A mellékelt `*.resz.html` a Design rajza (a lap `section`-je, benne az asztali és a telefonos képernyő, alatta a Tibor-táblázat és a „HÁTRÉBB KERÜLT” lista). Ami a rajzon van, az kerül a képernyőre, ugyanabban a sorrendben, ugyanazokkal a méret-tokenekkel. Ami nincs a rajzon, azt NEM rakod ki. A Tibor-táblázatot és a „HÁTRÉBB KERÜLT” listát NEM építed meg (az a rajz magyarázata).
- **Alapelemek:** a mellékelt `R15.tsx` (`KerdesCim`, `FoGomb`, `HalkGomb`, `HalkLink`, `Teendo`, `Info`, `Halad`, `KeszPillanat`, `Baj`, `Reszletek`) — ezeket használod, nem írsz helyettük sajátot. Mindegyik viszi a `data-r15` jelölést; ahol a rajz `data-r15="…"`-t ír és nincs rá alapelem (pl. `eredmeny`, `sotet-sav`, `lebego`), a jelölést te teszed ki ugyanúgy.
- **Egy fő gomb képernyőnként** (`FoGomb`). Telefonon (≤ 600 px) a fő gomb a képernyő alján, rögzítve (a rajz telefonos képernyője szerint); asztalon a helyén.
- **Szöveg csak feliratkulcsból:** `const { t } = useFeliratok();` (`import { useFeliratok } from "../../nyelv/kliens";`), `t(kulcs, { param: érték })`. A kulcsok a mellékelt `feliratok.json` `hu` részében (előtag `r15.`) — CSAK ezeket használod; új kulcsot nem találsz ki. A helyettesítők `{n}`, `{nev}`, `{mikor}` stb. — pontosan a JSON szerint.
- **CSS:** külön fájl, a lap saját előtagjával (`r15k-` Kezdőlap, `r15h-` Hírek, `r15p-` Poszt). CSAK tokenek (`var(--…)`), ugyanazok, amiket a rajz használ; nyers px csak 1px keretre és a rajzban is nyers értékre. Tilos: `color-mix(`, `font-weight: normal/inherit` (normálhoz `font-weight: 400;`), csupasz `0` térköz helyett `var(--ter-0)`. A lap külső eleme `<main className="km-lap-keret r15-lap …">` — a `<main>`-re NEM teszel `max-width/width/margin/padding`-ot (a keretőr tiltja), a belső elrendezés egy belső `div`-en.
- **Adat:** a lap props-ként kapja (a kiszolgálói lap tölti), a típusok a mellékelt `tipusok.ts`-ben (`import type { … } from "../../r15/tipusok";`). Művelet után `useRouter().refresh()` frissít (`next/navigation`), kivéve ahol a feladat mást mond. Hívás: `import { hivas } from "../_kozos/kliens";` (`hivas(ut, "POST", torzs)` → `{ statusz, torzs }`).
- **Halott vezérlő nincs:** minden gomb és link a feladatban megadott helyre visz vagy a megadott végpontot hívja.
- TypeScript szigorú (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`), `"use client";` az első sor. React 19, Next 16.
- **Visszaadás:** minden fájl egészben, így: `=== FÁJL: <út> ===` … `=== FÁJL VÉGE ===`. Semmi más szöveg, magyarázat nélkül.
