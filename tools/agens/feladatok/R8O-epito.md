Vilmos elfogadta az R-8 rajzot (2026-09-15). A három lap mellékelve `.dc.html`-ként (`ElsoBeallitas-1`, `ElsoBeallitas-Dolgozik`, `ElsoBeallitas-Jovahagyas`): a szerkezet és a szövegek onnan; az inline stílusokat NEM másolod — csak tokenek (`var(--…)`), meglévő osztályok (`km-lap-keret` a `<main>`-en — kötelező; `km-orb` az AI-korong; `km-grad` a gradiens szó; `km-emelkedik`). A mai öt képernyő (`/szervezet/uj` + `/onboarding/1`, `/2`, `/3` + `/onboarding/kesz`) helyett: `/szervezet/uj` MARAD (a név), utána `/onboarding` EGY lap három állapottal (űrlap → dolgozik → átnézés). Vasszabály: ami a rajzon nincs, nem kerül ki; ami mögött nincs gépezet, nem kerül ki (lásd: „Mely oldalakat figyeljük" — nincs forrás-ajánló, ezért a sor ÜRES lista + beviteli mező, nem AI-javaslat).

TypeScript 7 strict, Next.js 16, React 19. `=== FÁJL: <út> ===` … `=== FÁJL VÉGE ===`. TELJES fájlok az újakhoz; RÉSZLET (`_RESZLET-….md`, CSERE-blokkok, RÉGI szó szerint) a meglévőkhöz. ## MÉRT tények / meglévő gépezet (mellékelve)
- A piszkozat: `OnboardingPiszkozat` (`@km/contracts`, mellékelt részlet): `bemutatkozas { nev, weboldal, leiras, osszefoglalo, osszefoglalo_forras, osszefoglalo_modositva, … }`, `kommunikacio { celkozonseg(+_forras,_modositva,_kesobb), cel(…), nyelvek, nyelvek_javasolt, hangnem_leiras, hangnem_minta, hangnem_nyelv, hangnem_forras, … }`, `arculat`. - AI-lépések (mind meglévő végpont): `POST /api/onboarding/osszefoglalo` `{ nev, forras_tipus: "weboldal"|"leiras", weboldal, leiras }` → `{ osszefoglalo, forras }` (a `Lepes1.tsx`-ben a hívás és a beolvasztás mintája); `POST /api/onboarding/javaslatok` (törzs nélkül; a piszkozatból dolgozik) → `JavaslatokValasz { celkozonseg, cel, hangnem_leiras, hangnem_minta, nyelvek }` → `javaslatokBeolvaszt(p.kommunikacio, v)` (`@km/onboarding-core`; a `Lepes2.tsx`-ben a minta); a hírfigyelés javaslata: `POST /api/hirfigyelo/beallitas/javaslat` `{ szabad_szoveg? }` → `{ hirfigyelo: { tervezet: Beallitas } }` — MA a TÁROLT profilból dolgozik, ami a jóváhagyás előtt még nincs → ezért a végpont új, választható mezőt kap: `profil_tervezet` (lásd 4.).
- Jóváhagyás: `POST /api/onboarding/jovahagyas` (törzs nélkül; a piszkozatból profil) → 200 `{ profil }`; hiba 400 `{ hiba, mezok }` / 409 `NINCS_PISZKOZAT`.
