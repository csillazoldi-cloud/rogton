# F-8.1 k/2 · Építő — a webalkalmazás két új végpontja: forrás címének módosítása és eltávolítása, élő próbával

CÉL: `PUT /api/hirfigyelo/forrasok/[id]` (cím módosítása) és `DELETE /api/hirfigyelo/forrasok/[id]` (eltávolítás) a hírfigyelő közös kapuján át, plusz egy élő próbafájl, ami a futó kiszolgáló ellen bizonyítja őket.
Két fájlt adsz vissza.

TÉNYEK (készen van, nem kell ellenőrizni):
- A mag (`@km/news-monitor-core` 0.3.0) exportálja: `forrasCimModosit(k, ktx, forrasId, ujCim)` és `forrasTorol(k, ktx, forrasId)` → `{ ok: true, forras } | { ok: false, hiba, reszlet? }`.
  Hibák: `NINCS_JOG`; `ERVENYTELEN_ADAT` + `reszlet: "nincs_forras"` (ismeretlen id) vagy `reszlet: "ervenytelen"` (nem cím). A tár-port (`forrasTorol`) mindkét befogadóban megvan.
- A minta a mellékelt `apps/web/app/api/hirfigyelo/forrasok/[id]/ellenoriz/route.ts`: `kapu(keres, "szerkeszto")` → `eredmeny` vagy `Response`; `hostKontextus(eredmeny.fiok, eredmeny.szervezet.id)`; `kornyezet(eredmeny.szervezet.id)`;
  `eredmenyValasz(await …)` a mag eredményét fordítja HTTP-válaszra (200 `{ hirfigyelo: { forras } }`, a hibakódokat státuszra). Az importok relatív mélysége az ÚJ fájlban egy szinttel KEVESEBB, mint az `ellenoriz/route.ts`-ben
  (az új fájl `forrasok/[id]/route.ts`): `from "../../_kozos"` és `from "../../../../../hirfigyelo"`. A Next 16-ban a `params` ígéret: `ctx: { params: Promise<{ id: string }> }`.
- A `POST /api/hirfigyelo/forrasok` törzse `{ cim }` és `zod`-dal ellenőrzött (`forrasHozzaadSchema`) — a PUT ugyanígy `{ cim: z.string().min(1) }`, rossz törzsre `hiba({ hiba: "ERVENYTELEN_ADAT" }, 400)`.
- Az élő próbák mintája a mellékelt `apps/web/probak/hirfigyelo.proba.ts` 4. esete (forrás hozzáadása: `keres("/api/hirfigyelo/forrasok", { modszer: "POST", torzs: { cim }, sutik })` → 200, `torzs.hirfigyelo.forras.id`) és a `segedek.ts`
  (`keres()`, `PROBA_CIM`, `takaritas()`, `lezar()`). Fiók + szervezet létrehozása: nézd meg a `hirfigyelo.proba.ts` elejét (regisztráció → belépés → `POST /api/szervezet`), és ugyanúgy csináld, saját, egyedi e-mail-címmel (`proba-f81k-<idő>@proba.example`).
  A nézőt így hívod meg: `POST /api/tagok/meghivo` (tulajdonos) `{ szerep: "nezo" }` → 201 `{ hozzaferes: { jegy } }`; a másik fiók `POST /api/meghivo/elfogad` `{ jegy }` → 200.
