## 1. A csomag — `packages/visszajelzes-react/`
- `package.json` (név, `"type": "module"`, `exports: { ".": "./src/index.tsx", "./stilus.css": "./src/stilus.css" }`, scripts `tipus`), `tsconfig.json` (a news-monitor-core mintájára, `jsx: "react-jsx"`, `lib: ["dom", "es2022"]`), `README.md` (5–10 sor: mit ad, hogyan illeszd be — a komponens, a `kuldes`, a `feliratok`, a várt CSS-változók listája).
- `src/index.tsx` — `"use client"`; export `VisszajelzesModul` és a `VisszajelzesAdat` típus:
```ts
export type VisszajelzesAdat = { lap: string; lap_cim: string; elem: { cimke: string; szelektor: string; szoveg_reszlet: string } | null; kijelolt_szoveg: string; szoveg: string; nyelv: string; kep: string | null; ablak: { w: number; h: number } };
export type VisszajelzesFeliratok = { gomb: string; jelolo_mod: string; jelolo_szoveg: string; kilepes: string; ehhez: string; szovegresz: string; egesz_lap: string; mezo_sugo: string; jegyzet: string; kuldes: string; megse: string; feljegyeztuk: string; koszonjuk: string; hiba: string };
export function VisszajelzesModul(p: { kuldes: (adat: VisszajelzesAdat) => Promise<boolean>; feliratok: VisszajelzesFeliratok; nyelv: string; kepMaxSzelesseg?: number /* alap 480 */ }): JSX.Element
```
Viselkedés (az R-9 rajz szerint):
1. **Gomb** (rajz 5): jobb alul lebegő gomb `km-vj-gomb` (`position: fixed`), felirat `feliratok.gomb`, `data-vj` attribútum (minden saját elemünkön: `data-vj="1"` — a jelölő mód ezeket engedi át).
2. **Jelölő mód** (rajz 6): a gombra kattintva `jelol = true`: a `<body>` `km-vj-jelol` osztályt kap; fenn egy sáv `km-vj-sav` (`position: fixed; top`, jelvény `feliratok.jelolo_mod` + `feliratok.jelolo_szoveg` + jobbra gomb `feliratok.kilepes`). A lap vezérlői ilyenkor NEM indítanak semmit: `document.addEventListener("click" | "mousedown" | "mouseup" | "submit" | "keydown"(Enter/Space), kezelő, { capture: true })` — ha a cél NEM `[data-vj]` alatt van: `preventDefault()` + `stopPropagation()`, és kattintásnál a célt jelöljük (lásd 3.). Egér fölött: `mouseover` capture → a cél elemre `km-vj-cel` osztály (körvonal), `mouseout` → le. Escape → kilépés. A jelölő mód elhagyásakor minden figyelő és osztály lekerül (takarítás `useEffect`-ben).
3. **Kattintás egy elemre** → `elem` kiszámítása: `cimke` = az elem szerepe emberi nyelven + a szövege eleje (pl. `gomb „Mind a 8 új hír megtekintése"` — a tag alapján: button/a → „gomb"/„hivatkozás", h1–h3 → „cím", img → „kép", input/select/textarea → „mező", egyéb → „szöveg"; a szó a `feliratok`-ból NEM jön — ez a rögzített adat, magyarul, a rendszergazdának); `szelektor` = rövid CSS-út (tag + `#id` vagy az első `km-…` osztály, legfeljebb 4 szint, `>`-tal); `szoveg_reszlet` = `innerText.trim().slice(0, 300)`. Az elem `km-vj-jelolt` osztályt kap (erős körvonal), és mellé a **buborék** (rajz 6): `km-vj-bub` (`position: fixed`, az elem jobb széléhez, ha nem fér, alá/balra — `getBoundingClientRect`), benne: kis felirat `feliratok.ehhez` + a `cimke` halványan; `<textarea>` (`autoFocus`, `placeholder = feliratok.mezo_sugo`); alatta a jegyzet `feliratok.jegyzet`; gombok `feliratok.megse` (körvonalas) és `feliratok.kuldes` (gradiens fő gomb, `disabled` üres szövegnél).
4. **Szövegrész** (rajz 7): jelölő módban `selectionchange` figyelése: ha a kijelölés nem üres és nem `[data-vj]` alatt van → `kijelolt_szoveg = selection.toString().trim().slice(0, 1000)`, a buborék a kijelölés téglalapjához (`range.getBoundingClientRect()`), felirat `feliratok.szovegresz`, és a kijelölt szöveg idézve halványan; `elem` = a kijelölés közös szülőjéből számolva. A sávon egy gomb `feliratok.egesz_lap` is: ekkor `elem = null`, `kijelolt_szoveg = ""`, a buborék középen.
5. **Küldés**: `kep` = `toPng` a jelölt elemről (vagy a kijelölés szülőjéről; egész lapnál `document.body`-ról, `pixelRatio` úgy, hogy a szélesség ≤ `kepMaxSzelesseg`), `try/catch` — ha nem sikerül, `kep: null` (a küldés nem bukik el a kép miatt); a saját UI-elemeinket a kép előtt elrejtjük (`filter: (n) => !(n instanceof HTMLElement && n.dataset.vj)`); `lap = location.pathname + location.search`, `lap_cim = document.title`, `ablak = { w: innerWidth, h: innerHeight }`, `nyelv = p.nyelv`. `await p.kuldes(adat)`: siker → a buborék helyén 2,5 mp-re `km-vj-kesz` doboz (`✓ feliratok.feljegyeztuk` + `feliratok.koszonjuk`), a jelölt elem osztálya le, a lap visszaáll (a jelölő mód MARAD — a rajz szerint „jelölhetsz még, vagy kiléphetsz"); hiba → a buborékban `feliratok.hiba`, a szöveg megmarad.
6. Kisegítő: a sáv `role="status"`, a buborék `role="dialog" aria-modal="false"`, a gomb `aria-pressed`.
