# Feladat — FORDÍTÓ (E-16): a feliratok szerkesztőjének szövegei románul és angolul

Az alábbi magyar feliratokat fordítsd le ROMÁNRA és ANGOLRA. Egy kezelőfelület szövegei: a rendszer felületi szövegeinek szerkesztője,
ahol egy szervezet tulajdonosa a saját szervezetének átírhatja a feliratokat három nyelven; a „közös” = a minden szervezetnek szóló
alapszöveg; „saját” = a szervezet eltérő szövege; „tervezet” = még nem élő; „alkalmazás” = élesbe tétel; „tartaléknyelv” = ha egy
nyelven nincs szöveg, a magyar látszik. Stílus: rövid, hétköznapi, nem szakzsargon; román diakritikus jelekkel. A `{…}` helyőrzők
változatlanul maradnak; a „Magyar (eredeti)” / „Română” / „English” nyelvnevek maradjanak a saját nyelvükön. A csoportnevek
(`feliratok.csoport_*`) képernyők nevei. NE fordítsd az „Onboarding” szót.

Add vissza EGYETLEN fájlban (`=== FÁJL: feliratok-forditas.json ===`), JSON-ként: { "ro": {…}, "en": {…} } — minden kulcs mindkét nyelven, más nem.
