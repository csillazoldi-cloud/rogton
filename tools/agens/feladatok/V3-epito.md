## A SZERZŐDÉS (V1)
- `GET /api/visszajelzes[?allapot=uj|elfogadva|kesz]` → `{ visszajelzes: { tetelek: Visszajelzes[] } }`, ahol `Visszajelzes = { id, szervezet_id, szervezet_nev, fiok_id, fiok_nev, lap, lap_cim, elem: { cimke, szelektor, szoveg_reszlet } | null, kijelolt_szoveg, szoveg, nyelv, kep: null, ablak: { w, h }, allapot: "uj"|"elfogadva"|"kesz", letrehozva: ISO, csomag_id: string | null }`; 403, ha se rendszergazda, se tulajdonos.
- `GET /api/visszajelzes/<id>/kep` → `{ visszajelzes: { kep: string | null } }` (data URL).
- `PATCH /api/visszajelzes/<id>` `{ allapot }` → 200.
- `GET /api/visszajelzes/csomag` → `{ visszajelzes: { csomagok: JavitoCsomag[] } }`, `JavitoCsomag = { id, nap: "YYYY-MM-DD", osszefoglalo, tetelek: [{ id, cim, javaslat, sulyossag: "kicsi"|"kozepes"|"nagy", lapok: string[], visszajelzes_ids: string[], allapot: "javasolt"|"elfogadva"|"kesobb"|"nem" }], visszajelzes_db, letrehozva }`.
- `POST /api/visszajelzes/csomag` `{ nap? }` → `{ visszajelzes: { csomag: JavitoCsomag | null } }` (csak rendszergazda; 503 AI-hibánál `{ hiba: "AI_…" }`).
- `PATCH /api/visszajelzes/csomag/<id>` `{ tetel_id, allapot }` → 200 (rendszergazda).
- Feliratok: `vj.lista_cim, vj.csomag_cim, vj.oszlop_mikor, vj.oszlop_hol, vj.oszlop_mit, vj.oszlop_kep, vj.oszlop_allapot, vj.allapot_uj, vj.allapot_elfogadva, vj.allapot_kesz, vj.nincs_meg, vj.csomag_keszit, vj.csomag_keszul, vj.csomag_nincs, vj.csomag_ures, vj.tetel_elfogadom, vj.tetel_kesobb, vj.tetel_nem, vj.sulyossag_kicsi, vj.sulyossag_kozepes, vj.sulyossag_nagy, vj.visszajelzes_db ({n}), vj.ai_jelveny, vj.megnezem_kepet, nav.visszajelzesek`; meglévők: `kozos.bezaras`, `hf.ujra`.
