# R-7b 08 · Építő — a források blokkja (`apps/web/app/hirfigyelo/beallitas/Forrasok.tsx`): állapot szóban, sorműveletek (Újrapróbálás · Cím módosítása · Eltávolítás)

CÉL: a mellékelt `Forrasok.tsx` a Design R-7b rajzának 08. artboardja („2. Mely oldalakat figyeljük?") szerint: minden forrássor az állapotát EGY emberi mondattal mondja, és a szerkesztőnek három művelete van. Egy fájlt adsz vissza egészben.

TÉNYEK (mérve):
- A gépezet KÉSZ (news-monitor-core 0.3.0): `POST /api/hirfigyelo/forrasok/[id]/ellenoriz` (újraellenőrzés, BÁRMELY állapotban hívható) → 200 `{ hirfigyelo: { forras } }`; `PUT /api/hirfigyelo/forrasok/[id]` `{ cim }` → 200 `{ hirfigyelo: { forras } }` (az új cím ellenorzes_alatt állapotba kerül; 400 `ERVENYTELEN_ADAT` ha nem cím); `DELETE /api/hirfigyelo/forrasok/[id]` → 200 `{ hirfigyelo: { forras } }`. A `hfKeres<T>(ut, modszer, torzs)` → `{ statusz, torzs, hiba }` — a `torzs` a `hirfigyelo` burok NÉLKÜL érkezik (a mai kód `v.torzs.forras`-t olvas — maradj ennél a mintánál).
- Feliratok (0064, MEGVAN): `hf.forrasok_kerdes` „2. Mely oldalakat figyeljük?", `hf.forras_hozzaadas` „Hozzáadás", `hf.forras_ok` „Ezt az oldalt naponta figyeljük.", `hf.forras_hiba` „Ezt az oldalt most nem tudtuk feldolgozni.", `hf.forras_korlatozott`, `hf.forras_nem_tamogatott`, `hf.forras_ellenorzes` (ellenőrzés alatt — „Ezt az oldalt most nézzük meg."), `hf.forras_ujraprobalas` „Újrapróbálás", `hf.forras_cim_modositas` „Cím módosítása", `hf.forras_eltavolitas` „Eltávolítás", `hf.forras_eltavolitas_kerdes` „Biztosan eltávolítod? A már begyűjtött hírek megmaradnak.", `kozos.megse`, `kozos.rendben`, `hf.nem_mentett`. A régi kulcsok (`hf.srcAddPh`, `hf.srcAddBtn`, `hf.srcAddBad`, `hf.saveFailTitle`, `hf.betoltes_hiba`, `hf.ujra`, `hf.javaslatFolyik`, `hf.honestyNote`, `hf.srcGroup*`, `hf.srcAiWarn`) élnek — használd, ahol az elem marad.
- A hiba okát fordító `HIBA_FELIRAT` és `hibaSzoveg()` marad: a mondat után zárójelben/másodlagos sorban a konkrét ok (`hf.srcErr*`).

MIT CSINÁLJ (a rajz szerint):
1. **Fejléc**: a blokk címe `hf.forrasok_kerdes` (a szülő adja vagy itt — itt tedd a kártya tetejére, `h2`-ként, ha a mai fájlban nincs cím).
2. **Sor**: a forrás neve (`forrasNev`, `title` a teljes cím) · az **állapot mondata** (`hf.forras_ok` / `hf.forras_ellenorzes` / `hf.forras_hiba` / `hf.forras_korlatozott` / `hf.forras_nem_tamogatott`) a mai `data-allapot` jelvény HELYETT (a jelvény elmarad — szó helyettesíti; a színt a CSS adja `data-allapot` szerint, a `--warn` csak a hibás állapotnál) · alatta halkan a részlet (`hibaSzoveg`, ha van; `hf.srcLastOk` ha volt sikeres) · **három művelet** (csak `szerkesztheto`-nek): `hf.forras_ujraprobalas` (→ ellenoriz; minden nem-`hasznalhato` állapotban látszik; `hasznalhato`-nál nem), `hf.forras_cim_modositas` (→ a sor helyén egy `input` az aktuális címmel + `kozos.rendben`/`kozos.megse`; Enter = rendben; PUT; 400-nál `hf.srcAddBad`), `hf.forras_eltavolitas` (→ a sor helyén megerősítés: `hf.forras_eltavolitas_kerdes` + `kozos.rendben` (DELETE) / `kozos.megse`). Folyamatban lévő műveletnél a gombok `disabled`, a folyó soron `hf.javaslatFolyik`.
3. **Hozzáadás**: a mező + a gomb marad (`hf.srcAddPh`, `hf.forras_hozzaadas`); Enter is hozzáad; hozzáadás után azonnal ellenőrzés (mai működés).
4. A csoportosítás (saját · sajtó · AI) marad; az `hf.honestyNote` mondat marad a blokk alján. A betöltési hiba helyben újrapróbálható (mai `hf.ujra` gomb — marad).
5. Osztálynevek: a meglévők maradnak; ÚJ: `km-hf-be-forras-mondat` (az állapot mondata), `km-hf-be-forras-muveletek` (a három gomb sora), `km-hf-be-forras-szerkeszt` (a cím-mező sora), `km-hf-be-forras-megerosit` (az eltávolítás megerősítő sora). A gombok osztálya `km-hf-be-forras-gomb` (mai). A CSS-t ÉN igazítom.
